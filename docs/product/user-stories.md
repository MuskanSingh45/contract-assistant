# User Stories

## Contract management

- As a user, I want to upload a contract so that the system can analyze it.
- As a user, I want to see all contracts in one place so that I can find a contract quickly.
- As a user, I want to see contract versions so that previous documents are not lost.

## Extraction

- As a user, I want parties extracted so that I do not have to search manually.
- As a user, I want effective and expiration dates extracted.
- As a user, I want renewal and notice terms identified.
- As a user, I want obligations and responsible parties identified.

## Traceability

- As a user, I want every important extracted result to show its source.
- As a user, I want to open the source context before accepting a result.

## Review

- As a user, I want to approve extracted information.
- As a user, I want to edit incorrect information.
- As a user, I want to reject unsupported information.
- As a user, I want confidence separated from approval status.

## Renewals

- As a user, I want notice deadlines calculated from contract rules.
- As a user, I want renewal-related dates visible without reading the entire contract.
