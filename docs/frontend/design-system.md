# Design System

## Direction
Use provided reference screens as visual inspiration, not a requirement for pixel-perfect reproduction.

## Principles
- Clean enterprise interface
- Clear information hierarchy
- Readable tables/cards
- Consistent spacing
- Clear primary actions
- Obvious review states
- Easy source access

## Priority
1. Upload/analyze flow
2. Contract details
3. Review queue
4. Source citation
5. Obligations
6. Renewals

Avoid spending MVP time on complex analytics, full PDF rendering, advanced settings, or a large standalone design system.
